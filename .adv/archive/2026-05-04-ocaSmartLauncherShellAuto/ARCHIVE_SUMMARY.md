## Wisdom Accumulated

- **[pattern]** For config fields where absent should default but explicit zero should be invalid, keep public scalar fields and add unexported `...Set` booleans captured via `UnmarshalTOML`. Validation can then distinguish absent from explicit zero without pointer-heavy call sites.
- **[pattern]** OCA-owned shell state can stay test-isolated without a new env var by deriving `~/.config/oca` as a sibling of `OCA_OPENCODE_CONFIG_DIR`. Tests override `OCA_OPENCODE_CONFIG_DIR=/tmp/.../opencode`, so env.sh lands at `/tmp/.../oca/env.sh` instead of production home.
- **[gotcha]** When adding post-apply behavior, patch the common `emitPlanOrApplyWithOpts` path, not only special targets like temporal. Target-specific tests can pass while `apply --target plugins` still skips the post-action if the common emitter is missed.
- **[success]** `git ls-remote -- <source> <ref>` with `GIT_TERMINAL_PROMPT=0` detects remote plugin updates without changing `refs/remotes/origin/*`; local bare-remotes make this property easy to prove in tests by comparing remote-tracking refs before/after.
